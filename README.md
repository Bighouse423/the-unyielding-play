# THE UNYIELDING — public playtest (m7d)

A frozen snapshot of **THE UNYIELDING** for friends to play in the browser. This copy stays as it is while the game is still being worked on.

**Play here:** https://raw.githack.com/Bighouse423/the-unyielding-play/main/index.html

Open the link, wait for the title screen, then click (or press Enter / Space) to start. Use the mouse and keyboard, or a gamepad. Click once so the music and sound effects can start.

This is a work-in-progress playtest, not the final $15 release.
