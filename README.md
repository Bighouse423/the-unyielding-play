# THE UNYIELDING — public playtest (m7d)

A frozen snapshot of **THE UNYIELDING** for friends to play in the browser. This copy stays as it is while the game is still being worked on.

Everyone starts a brand-new game: no unlocks, no bought weapons, no shards, and no progress from anyone else's save (including the developer's).

**Play here:** https://rawcdn.githack.com/Bighouse423/the-unyielding-play/99fcc7e95af4e63612808b2117c93902a67e70e3/index.html

The first visit may show an "Open the page" notice from the host — click that once, then wait for the title screen and click (or press Enter / Space) to start. Use the mouse and keyboard, or a gamepad. Click once so the music and sound effects can start.

This is a work-in-progress playtest, not the final $15 release.
